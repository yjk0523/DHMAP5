네이버지도 Client ID 입력

이 지도는 네이버클라우드플랫폼(NCP) Maps API로 표시됩니다. 아래 절차로 발급받은 Client ID를 입력하면 지도가 로드됩니다.

⚠ 네이버클라우드플랫폼은 결제수단(카드) 등록이 있어야 콘솔 이용이 가능합니다 (Maps API 자체는 무료 사용량 제공). 이 부분이 카카오맵과 다른 점입니다.
  1. console.ncloud.com 접속 후 회원가입/로그인 → 결제수단(카드) 등록
  2. [Services] → [Application Service] → [AI·NAVER API] → Maps → [이용 신청]
  3. [Application 등록] → 이름 입력 → 서비스 Web Dynamic Map 선택
  4. 서비스 환경(Web 서비스 URL)에 이 파일을 사용할 도메인 등록
    (예: 로컬 테스트 시 http://localhost:포트번호, 사내 서버 배포 시 해당 도메인 · HTTPS 권장)
  5. 등록한 Application 상세화면에서 Client ID 복사
  6. 아래에 Client ID 입력 후 [지도 불러오기] 클릭
지도를 불러오지 못했습니다. Client ID 값과 서비스 URL(도메인) 등록 상태를 확인해 주세요.
